A program that names the one word to erase from the dictionary forever: **colonel** — the word spelled nothing like it sounds. It is pronounced "kernel", so deleting it is the one edit that makes English honest. It writes exactly that one word, and nothing else, to `entry.txt`.

## Run it

```sh
python3 main.py
```
